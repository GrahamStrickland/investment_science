% Exercise 2.5
Given payments $x_k = 500000$, for $k = 0, 1, \ldots, 20$, and $r = 0.1$, we
have the following present value:
\begin{equation*}
    \begin{split}
        \text{PV} &= \sum_{k = 0}^n{\frac{x_k}{{(1 + r)}^k}} \\
        &= \sum_{k = 0}^{20}{\frac{500000}{1.1^k}} \\
        &\approx \$4,756,781.86,
    \end{split}
\end{equation*}
so that the present value of the prize is \$4,756,781.86.

We use the following to calculate the approximate present value:
\begin{lstlisting}
>>> from investment_science.cash_flows import present_value
>>> present_value([500_000.0] * 21, 0.1)
4756781.859879279
\end{lstlisting}
