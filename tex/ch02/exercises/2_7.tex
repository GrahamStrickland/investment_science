Delaying the harvest another year with the same prevailing interest rate of
10\% and the return $R$ would yield the formula
\[
    \text{NPV} = -1 + R / {(1.1)}^2 < 1.48,
\]
so that we have
\begin{equation*}
    \begin{split}
        R / {(1.1)}^2 &< 2.48 \\
        \Leftrightarrow R &< {(1.1)}^2 \cdot 2.48 \\
        &= 2.904,
    \end{split}
\end{equation*}
so that $x = 2.904$.
